# TikTok correction (2026-09-08)

TikTok uses the unmodified full-colour `TikTok_Icon_Black_Square.png` from
[TikTok for Developers design guidelines](https://developers.tiktok.com/docs/en/getting-started-design-guidelines).
The linked [official logo pack](https://sf16-va.tiktokcdn.com/obj/eden-va2/uvzhqeh7nuhd/tt4d/logo-pack.zip)
contains this PNG in its TikTok Icons directory. Extract that file without recolouring or inversion.
Brand ownership remains with TikTok; the guidelines require permission for logo use.
This reference identifies the example deal's source, not an integration or endorsement.
The legacy monochrome TikTok SVG is no longer rendered.
